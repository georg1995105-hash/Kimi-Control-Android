# Kimi Control Android

Нативный Android-клиент для удалённой работы с официальным Kimi Code CLI. Приоритеты: русский интерфейс, надёжность и безопасность сервера.

## Текущий этап: 0.1 — проект загружен в GitHub

**Реализовано в коде:**
- Jetpack Compose, русскоязычный адаптивный экран чата.
- Русская диктовка через системный Android Speech Recognizer (ru-RU) с редактированием перед отправкой.
- Выбор фотографий и документов через системный Android picker, без разрешения на весь диск.
- Просмотр локальных вложений и сохранение черновиков в памяти приложения.
- Светофор состояния «Не подключено»: приложение **не имитирует** подключение к Kimi.
- GitHub Actions собирает debug APK на push.

**Пока не реализовано:** реальная отправка сообщений агенту, перенос файлов на сервер, скачивание готовых Markdown/PDF/ZIP, постоянное хранение истории, фоновая работа. Это отдельные этапы после проверки API Kimi CLI.

## Сборка

GitHub → Actions → Build Android Debug APK → скачать артефакт `Kimi-Control-debug-apk`.

Требуется Gradle 8.13, JDK 17, Android SDK 35. Запуск локально: `gradle :app:assembleDebug`.

## Планы: безопасный доступ к Kimi

В официальном Kimi CLI есть экспериментальный серверный API. Конкретные REST/WebSocket события, методы загрузки файлов и разрешения сверим с текущей версией CLI перед внедрением. На CONTROL API должен оставаться привязанным к локальному интерфейсу. Для телефона будет защищённый канал с авторизацией; никакие ключи или IP инфраструктуры не добавляются в публичный репозиторий.

## Голос

`ru-RU` задаёт язык движку Android, но не гарантирует качество распознавания и может использовать сетевой сервис производителя. Текст всегда можно исправить до отправки. Более умное распознавание технических терминов потребует отдельного механизма с контролем приватности.

## Безопасность

Никогда не добавлять SSH-ключи, токены API, пароли, реальные конфиги, production IP, файлы сессий. Результаты тестов должны быть проверены на телефоне до подключения к боевой инфраструктуре.
